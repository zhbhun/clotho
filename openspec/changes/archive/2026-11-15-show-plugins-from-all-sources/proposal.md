# Proposal

## Why

The All view still hides same-name entries from other marketplaces, preventing users from comparing and choosing their source.

## What Changes

- Show each marketplace's catalog entry in All, including entries with the same name.
- Track installation and actions by the full plugin ID in every view.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `plugin-settings-pages`: Show source-specific plugin entries together and manage their exact identities.

## Impact

Marketplace catalog rendering and its tests; no IPC changes.
