## ADDED Requirements

### Requirement: Open the skill marketplace from installed skills

The installed Skills page SHALL show a marketplace action at the right of the installed-count header, including when the list is empty. Activating it SHALL open the Skills tab of Marketplace in the current settings window.

#### Scenario: Find a skill to install

- **WHEN** the user activates the marketplace button from the installed Skills page
- **THEN** the sidebar selects Marketplace and the Skills catalog opens with its search and installation actions
